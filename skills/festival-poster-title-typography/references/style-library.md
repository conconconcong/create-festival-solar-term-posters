# 标题字原型库

以下八类原型来自节日节气海报样本的可泛化特征，不用于复刻样本中的具体字形。选择一个主原型，再按画面增加至多一个轻量修饰。

## T01 干刷碑势

- 适配：暑去秋来、风、热浪、转折、城市动势、雄浑或爽朗场景。
- 字形：大开大合的行草或榜书骨架，粗细反差强，横画可长，重心略有错落。
- 触感：飞白、枯笔、墨迹断续；边缘自然毛涩，不能像软件统一噪点。
- 版式：两三字竖排最有张力；允许一个长笔画牵引视线，但不穿过关键主体。
- 色效：赭红、焦橙、深墨或从画面暖色物候取样；通常不加厚重阴影。
- 避免：浪漫、极简科技或需要端庄精密识别的场景。

## T02 月光柔行

- 适配：七夕、元宵夜、月夜、星河、相守、思念、梦境和轻柔东方叙事。
- 字形：秀逸行书或行草，笔锋圆润，收笔细长，动势连续但不过分狂放。
- 触感：丝绢、软墨或微湿笔；飞白少而精。
- 版式：竖排两三字，或短横排；可用一条克制的弧线收笔呼应云、月或银河。
- 色效：月白、淡紫、银蓝；在暗背景上用低半径柔光，不做霓虹灯管感。
- 避免：高饱和多色、硬金属边、过粗黑描边。

## T03 朴拙宽笔

- 适配：立秋、丰收、土地、乡野、童趣、手作纸张、温暖而不奢华的画面。
- 字形：宽扁厚重的楷意手写，结构方中带圆，字腔开阔，局部略不对称。
- 触感：木刻、粉蜡、粗纸印刷或干刷；整体必须保持成块可读。
- 版式：两字竖排或紧凑方形字组，适合与圆形构图、俯拍构图配合。
- 色效：麦黄、纸白、浅金、土色；可有轻微明暗纹理，不做镜面金属。
- 避免：把朴拙做成幼儿涂鸦，或纹理过重导致笔画破碎。

## T04 几何物候字

- 适配：现代品牌感、晴朗高键画面、芒种/谷雨/春分等具有明确物候符号的主题。
- 字形：几何无衬线或定制单线/中细线标题，横竖关系清楚，留白理性。
- 触感：洁净、平面、无明显笔刷；可有极轻的圆角。
- 版式：竖排可强调修长感，横排可强调秩序；笔画内最多嵌入一个麦穗、雨滴、芽叶、月相等符号。
- 色效：白色或画面主色的高对比浅色；优先纯色，少用发光。
- 避免：为了图形梗改变字的基本结构，或每个字都塞入图标。

## T05 生长锐行

- 适配：植树节、清明踏青、春生、向上生长、行动号召、生命力强的绿色场景。
- 字形：瘦长锐利的行书，撇捺伸展，竖向牵引明显，起收笔有叶尖般方向性。
- 触感：湿墨为主、轻飞白为辅；速度感中等偏强。
- 版式：竖排可与树干、枝叶或阳光方向形成呼应；保留呼吸空间。
- 色效：深绿、墨绿、青绿或深墨；从植被暗部取色，确保与亮草地分离。
- 避免：荧光绿、藤蔓缠满字形、过细笔画消失在叶片背景中。

## T06 水墨光笔

- 适配：惊蛰、谷雨、雨水、雷电、露水、晨雾、湿润森林及带超现实光感的场景。
- 字形：挥写感行草，主笔势明显，可有一条长收笔模拟电光、雨线或水汽。
- 触感：湿笔、边缘晕染、微粒水雾；骨架仍需清晰。
- 版式：竖排或斜向竖排，顺着环境的光束和植物方向走。
- 色效：冷白、青白、浅蓝；允许窄幅内发光和柔和外溢光。
- 避免：把外发光做成粗霓虹描边，或让长尾误连到另一个字。

## T07 烟火圆笔

- 适配：腊八、冬至、年夜饭、团圆、家庭、热汤、室内暖光和亲切民俗场景。
- 字形：圆厚楷意或温和行楷，笔画有手写起伏，字面饱满但不拥挤。
- 触感：粉笔、软毛刷、米纸或轻颗粒白墨；可将一处收笔化为蒸汽般曲线。
- 版式：三字可竖排，两至四字可横排；围绕食物蒸汽留出呼吸。
- 色效：米白、暖白、朱红或深棕；暖背景上用细暗边或局部阴影提升分离度。
- 避免：冰冷几何线条、金属高光、把整组字做成可爱泡泡字。

## T08 冰雪绒刷

- 适配：元旦、新年、冰雪节、冬季庆典、热闹可爱和强红色年节画面。
- 字形：粗重手写黑体或毛刷体，结构稳定、横排优先，局部大小和基线可轻微跳动。
- 触感：绒雪、霜晶、粗粉笔或颗粒白漆；边缘粗糙但内部连续。
- 版式：四至六字横排或两行，适合大声量祝福语；英文小字只能作为用户明确要求的次级信息。
- 色效：雪白为主，可有很浅的冷灰阴影；红背景上不需要厚重发光。
- 避免：颗粒吃掉小笔画、星点过多变成装饰噪音、擅自增加中英文副标题。

## 组合规则

- 允许的次级修饰包括：T01 + 暖色飞白、T02 + 微水光、T03 + 纸纹、T04 + 单一物候符号、T05 + 湿墨、T06 + 长收笔、T07 + 蒸汽尾、T08 + 霜晶颗粒。
- 不要把“书法骨架 + 几何镂空 + 立体金属 + 霓虹光 + 雪粒”叠成一组字。主风格必须一眼可辨。
- 有萌宠或卡通角色时，仍以节日语义和环境材质为主。角色可提高亲和力，但不自动把标题变成圆体。
- 当八类都不完全适合时，选择结构最近的一类，只替换一个维度，例如保留 T04 的几何骨架、改用节庆红纸纹；不要凭空扩展成无关的商业字体体系。
