# Sunny & Molly 节日海报

## 快速默认

- 无字主视觉默认只生成 **一次**；标题素材由标题技能单独生成，不计入主视觉次数。
- 标题设计交给 `$festival-poster-title-typography`；默认直接生成独立原创标题素材，不使用本地或系统字体排成最终标题。
- 标题可以独立成层，但不能脱离成片盲做：先读取实际标题区的明度、主色、光向和留白形状，再决定字色、方向与材质；浅背景优先深色实字，深背景才用浅色字。
- 标题默认生成一次；出现错字、增缺字、伪字、误连、脏底或缩略图不可读时，只允许一次针对性重生。第二次仍失败就明确报告，不得静默回退本地字体。
- 主视觉默认采用大胆、非模板化构图。除非用户要求端庄正式，不使用“正中对称 + 两个角色并排坐 + 道具居中 + 平视全身”的安全模板。
- 单张海报默认只选择一种最自然的业务模式：**风险发现 / 准备清单 / 保障科普 / 应急路径 / 长期陪伴**。业务必须长在场景、道具、动线与角色互动里，不另加独立“保险创意”模块。
- 用户要求“5 个创意”时，才分别按五种业务模式给出五条短简报；除非用户明确要求全部生图，否则只生成选中的一张。
- 已合格的层始终复用。修改文案、位置、Logo 或二维码只重新合成；局部反馈只重做对应层。
- 除节点名称、必需素材或会改变创意方向的信息确实缺失外，直接推断并执行，不反复确认。

## 流程

### 1. 锁定一行简报

内部只记录：`节点符号｜业务模式与母题｜品牌价值｜双角色互动｜场景/主道具｜镜头｜三色以内｜标题｜左下两行文案`。

从五种模式中选一项：天气、误食、户外和出行节点优先“风险发现”；季节养护与日常生活优先“准备清单”；知识型节点优先“保障科普”；假期与突发场景优先“应急路径”；情感、家庭和年末节点优先“长期陪伴”。用户已给出明确业务角度时沿用，不强行换模式。详细转译规则见 `references/creative-guide.md`。

Sunny 与 Molly 必须共同完成故事，保持犬猫身体结构；用户指定飞行或骑乘时，让所有爪子稳定承重，不使用人手、工具、缰绳或危险姿态。左下文案默认 10–16 个字，不重复标题，不写日期、英文或硬销售话术。

### 2. 一次生成无字主视觉

以角色母版为参考，写一段紧凑提示词并调用图像生成工具。把选定业务模式转译成一个可见机关：风险提示可用异常光点或危险路径，准备清单可用三处有序检查点，保障科普可用清晰分区与透明层次，应急路径可用连续动线，长期陪伴可用时间轨迹或健康档案意象。不得直接画文字、保单、合同、医院、盾牌或恐惧画面。

业务母题必须进入主场景、主道具、角色动作或构图动线，不能只在提示词末尾追加一句保险口号。画面不得出现任何文字、Logo、二维码或伪文字；顶部 Logo、上半标题、左下文案与右下二维码区域保留自然低细节空间。

构图必须先确定一个主机关，并至少同时改变视角、尺度、层次或动势中的两项。优先使用偏心主体、非常规高低机位、前景大遮挡、角色远近尺度差、局部裁切、强对角线或弧线引导；让 Sunny 与 Molly 通过动作和视线形成故事，不把二者摆成面向镜头的并排纪念照。具体约束见 `references/creative-guide.md`。

只有身份、肢体、核心动作或构图明显失败时，才做一次针对性重生。轻微色差、装饰偏差或可由合成解决的问题不重生。

### 3. 标题模块

调用 `$festival-poster-title-typography`：先取得标题原文、原型、方向、颜色、效果、落位和宽度比例，再让该技能基于实际主视觉直接生成独立标题素材。

标题规格必须以已生成的主视觉为输入：在预定标题框内检查背景平均明度与纹理密度。标题与背景先保证明度分离，再做材质呼应；不得把透明标题素材直接贴到与其明度接近的区域。

合成路径统一使用标题素材：

```bash
python3 scripts/compose_poster.py \
  --input <无字主视觉.png> \
  --title-art <标题字素材.png> \
  --title-box 160,260,760,280 \
  --copy "第一行\n第二行" \
  --logo auto --qr auto \
  --output <最终海报.png>
```

把标题模块返回的落位和宽度比例换算为 `--title-box`；竖排标题使用窄高框，横排或两行标题使用宽框。标题生成时同时提供实际主视觉作为配色与光向参考，但不得提供本地字体、系统字体、SVG 字骨或字体截图。假透明棋盘格视为脏底，不得直接抠取使用。

标题第一次生成不合格时，只把准确原文、失败字符、背景和误连问题反馈给标题技能做一次针对性重生；第二次仍失败则停止并报告，不能用 `--title-text` 或本地字体悄悄替换。

### 4. 检查与交付

实际打开 1080×2333 px 成片和 15%–20% 缩略图，确认：角色身份与肢体正确；节点一眼可懂；标题逐字准确、无遮挡且缩小仍清楚；左下文案为阿里妈妈方圆体 Bold、1080 宽画布下每行同为 43 px；Logo 与二维码来自真实资产；二维码静区完整。

只交付一句话创意、所选业务模式、标题与文案、最终海报。一句话创意需同时说清节点机关、角色互动和业务价值。用户没有索要时，不输出完整推理、五个候选方向、重复规则或冗长提示词。
