# 最终检查

在完整尺寸和缩略图各检查一次：

- 节点一眼可懂，物候或民俗准确，只有一个核心隐喻。
- Sunny 与 Molly 的身份、服装、比例、肢体和互动符合母版。
- 动作保持犬猫结构；没有人手式抓握、双足劳动、额外或融合肢体。
- 主视觉没有生成文字、Logo、二维码或伪文字。
- 标题逐字准确且只出现一次，没有不透明底、脏边或遮挡。
- 左下文案逐字正确，使用阿里妈妈方圆体 Bold，与二维码保持安全距离。
- Logo 来自正确真实色版；二维码保持 176×208 基准比例与静区。
- 成片为 1080×2333 px 或 2 倍高清尺寸，已实际打开检查。

只返回失败层：主视觉问题重生主视觉，标题问题重生标题，排版或品牌问题重新运行 Python 合成。
