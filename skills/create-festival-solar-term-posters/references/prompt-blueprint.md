# 无字主视觉提示词

仅在用户要求完整提示词或主视觉约束复杂时读取。

```text
创作 1080×2333 px 的 Sunny 与 Molly 宠物险[节点]竖版无字主视觉，严格匹配角色母版。Sunny 为[必要身份特征]；Molly 为[必要身份特征]；保持既定比例、服装和配件。

[一个节点符号]通过[风险发现 / 准备清单 / 保障科普 / 应急路径 / 长期陪伴中的一项]表达[一个品牌价值]；把该业务模式转译为[一个可见场景机关]，不依赖文字说明。Molly 通过[自然动作]回应，Sunny 通过[自然动作]守护；场景为[一个主场景]，主道具为[一个]，镜头为[一种]，主色不超过三组。为顶部 Logo、上半标题、左下文案和右下二维码保留自然低细节区域。

只生成角色与场景；不要文字、字母、数字、Logo、二维码、水印或伪文字。不要身份漂移、服装互换、人手、人形腿、额外或融合肢体、爪子抓握工具、危险姿态、医院、伤口、盾牌、保单、合同或元素堆砌。
```

标题提示词与字体设计不属于本 Skill；交给 `$festival-poster-title-typography`。
